# Personal Reflection

Before researching this topic, I mostly thought about AI as a tool that simply helps programmers write code faster. After reading industry reports and statistics, my opinion became more detailed and balanced.

What surprised me most was how quickly companies are adopting AI in software engineering workflows. AI is already being used for coding, testing, debugging, and documentation in many real companies. I did not expect adoption to grow this rapidly.

At the same time, I became more concerned about overdependence on AI tools. If developers rely too heavily on AI-generated code without understanding it, they may lose important programming and problem-solving skills. This could create software quality and security problems in the future.

I also found it interesting that most reports do not predict the complete replacement of software engineers. Instead, they predict changes in developer responsibilities. Engineers may spend less time writing repetitive code and more time reviewing AI-generated solutions, designing systems, and solving complex problems.

This research helped me understand that learning programming fundamentals is still very important. Even if AI can generate code, developers must still understand how systems work, how to detect mistakes, and how to make good engineering decisions.

In the future, I think software engineers will need to continuously learn new technologies and adapt to changing tools. Personally, I believe I should improve not only technical programming skills, but also critical thinking, communication, and problem-solving abilities because these skills are difficult for AI to replace.

Overall, this research changed my perspective. I now see AI as a powerful assistant rather than a complete replacement for software engineers.
